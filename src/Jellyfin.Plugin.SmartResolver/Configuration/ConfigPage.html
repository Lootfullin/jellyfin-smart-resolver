Jellyfin Smart Resolver

Read-only resolver for nested series folders and movie names taken from video files.

Nested Series

Applied to the outer folder name in Custom Regex mode.

Movies

Example: (1979) Moonraker/Moonraker (1979) [WEB-DL].mkv. The navigation folder name is not used as the movie title.
