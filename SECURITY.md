# Security policy

The supported line is `0.1.x` on Jellyfin Server 10.11.11.

Report vulnerabilities privately through a GitHub Security Advisory once the
repository is published. Do not include private media paths, access tokens or
complete Jellyfin logs. Provide the smallest reproducible structure and the
relevant redacted log lines.

The plugin is designed to be read-only. Any behavior that modifies media files
should be treated as a security defect.
